# 🍱 식사 주문 계산기 (Meal Order Calculator)

팀원들이나 모임에서 식사 메뉴를 간편하게 취합하고, 개인별 주문 금액과 예산 초과 여부, 전체 총액을 자동으로 계산해 주는 **웹 기반 식사 주문 정산 도구**입니다. 별도의 백엔드 서버 없이 브라우저 내에서 작동하며, 로컬 저장소 및 File System Access API를 통한 클라우드/로컬 파일 동기화를 지원합니다.

---

## ✨ 주요 기능

* **자연어 주문 입력 파싱**:
* "홍길동: 김치찌개 공기밥2"와 같이 한 줄에 한 명씩 자유롭게 입력하면 메뉴와 수량을 자동으로 인식합니다.
* 첫 단어를 이름으로 자동 처리하는 옵션을 제공합니다.


* **가맹점(식당) 및 메뉴판 관리**:
* 식당별로 메뉴판을 분리하여 관리할 수 있습니다.
* 메뉴 가격뿐만 아니라 **별칭(Alias)**, **수량별 총액(Tier)**, 옵션(곱배기, 토핑, 개수형 옵션 등)을 상세하게 설정할 수 있습니다.


* **미등록 항목 예외 처리 및 추천**:
* 메뉴판에 없는 항목이 입력되면 자동으로 감지하여 '새 메뉴', '요청사항', '옵션' 등으로 간편하게 등록할 수 있도록 돕습니다.


* **예산 및 한도 관리**:
* 인당 한도 금액을 설정하여 초과 인원 발생 시 시각적인 경고(진행 바 및 배지)를 제공합니다.


* **주문 기록 및 날짜별 필터링**:
* 계산된 주문 내역을 가맹점별로 기록(차수별 저장)하고, 날짜별로 조회하거나 다시 불러올 수 있습니다.


* **공유 파일 동기화 (File System Access API)**:
* Chrome 및 Edge 브라우저에서 로컬 JSON 파일과 연동하여 여러 사용자가 데이터를 공유하거나 안전하게 백업할 수 있습니다.



---

## 🚀 사용 방법

1. 브라우저에서 `주문계산기_20261028.html` 파일을 엽니다.
2. 상단에서 주문할 **식당**을 선택하거나 [+ 식당 추가]를 눌러 새 식당을 등록합니다.
3. [메뉴판]을 펼쳐 메뉴와 가격, 옵션 등을 등록합니다.
4. **주문 입력** 텍스트 áreas에 아래 예시처럼 주문 내용을 입력합니다.
```text
홍길동: 김치찌개 공기밥2
김영희: 된장찌개 x2
박철수: 제육볶음 3개, 계란말이

```


5. **[계산하기 (Ctrl+Enter)]** 버튼을 눌러 결과를 확인합니다.
6. 계산된 결과를 바탕으로 [현재 주문 내역 기록]을 통해 기록을 남기거나 [결과 복사]를 통해 메신저 등에 공유할 수 있습니다.

## 🛠 기술 스택

* **Frontend**: HTML5, CSS3 (CSS Variables, 다크모드 자동 대응 지원), Vanilla JavaScript
* **Storage**: `localStorage`, `IndexedDB`, `File System Access API`
